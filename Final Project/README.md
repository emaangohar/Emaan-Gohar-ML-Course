# Final Project

## Amazon Food Reviews Sentiment Analysis

This project analyzes Amazon food reviews to predict customer sentiment using machine learning.

Models used:
- Logistic Regression
- Multinomial Naive Bayes
- Linear SVM

The project includes:
- Exploratory Data Analysis
- Text preprocessing
- TF-IDF feature extraction
- Model training
- Performance evaluation
- Business conclusions

This project demonstrates an end-to-end machine learning workflow for sentiment analysis using Python and Scikit-learn.
