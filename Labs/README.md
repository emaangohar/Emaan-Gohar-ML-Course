## Skills Learned

Throughout these labs, I learned how to:

- Load and clean datasets using Pandas
- Perform exploratory data analysis (EDA)
- Prepare data for machine learning
- Build regression and classification models
- Evaluate models using accuracy, precision, recall, and confusion matrices
- Apply clustering and dimensionality reduction techniques
- Tune machine learning models
- Understand fairness and bias in AI
- Build complete machine learning pipelines using Scikit-learn

These labs helped me develop practical machine learning skills using Python and Scikit-learn.
